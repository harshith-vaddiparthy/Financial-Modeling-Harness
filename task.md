# Specialist job

Build auditable operating financial models for founders and finance teams: intake opening balances and forecast drivers, distinguish source actuals from assumptions, calculate the linked statements and scenarios, inspect funding and unit economics, and deliver a verified model with its report.

Representative request: build a 36-month SaaS model, hire engineers and sales staff on specific dates, compare acquisition/churn assumptions, add one priced equity round, report the first cash deficit and prove all statement linkages.

Implemented runtime: portable Python engine plus native Hermes skill and optional stdio MCP tools. Hermes remains the conversational runtime and keeps its existing inference provider. This vertical does not turn a natural-language suggestion into a company actual or an automatic external transaction.
