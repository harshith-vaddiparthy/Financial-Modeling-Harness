# Completion contract

A completed model run includes its exact input and provenance, every requested scenario, monthly statements, annual summaries, applicable cohort/unit metrics, cash-breach and funding-gap analysis, domain limitations, seven statement checks per month, and a completed run manifest. JSON/CSV, Markdown and the HTML report are saved snapshots. They refresh only through a new calculation run.

The agent returns the run ID, verified artifact/report paths, verification result, scenario differences, material assumptions and the earliest financing decision implied by the forecast. Cite the input source/rationale for recommended driver changes. Clearly distinguish numerical reconciliation from the plausibility of assumptions.

For integration, report three separate outcomes: skill installed/discoverable, MCP registered/tested, and an actual Hermes agent turn that calls the tools. File copies or a standalone MCP response establish only their corresponding boundary. A live provider error leaves model-backed execution unverified even when the standalone engine works.
